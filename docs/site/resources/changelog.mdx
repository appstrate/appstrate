## Releases

Appstrate releases are published on GitHub:

**[github.com/appstrate/appstrate/releases](https://github.com/appstrate/appstrate/releases)**

Each release includes:
- Changes and new features
- Bug fixes
- Breaking changes if any
- Migration instructions when needed

## API Versioning

The API uses date-based versioning (Stripe pattern). The current version is `2026-03-21`.

See the `Appstrate-Version` header in the [API reference](/en/docs/api) for more details.
