Appstrate is open source (Apache 2.0, apart from the source-available `packages/module-ee`) and its community is public. Anyone who reports a bug, asks a question, improves the docs, or builds on the platform is welcome.

## Chat

## When to use what

- **Bug, crash, regression**: open an issue with the [bug report template](https://github.com/appstrate/appstrate/issues/new?template=bug_report.yml). Include steps to reproduce, what you expected, what happened, and your environment (OS, Bun and Docker versions).
- **Feature request**: open an issue with the [feature request template](https://github.com/appstrate/appstrate/issues/new?template=feature_request.yml). Describe the problem before the solution.
- **Large or breaking change**: propose it first, following the RFC process in [GOVERNANCE.md](https://github.com/appstrate/appstrate/blob/main/GOVERNANCE.md).
- **Security vulnerability**: do not open a public issue. Use [GitHub private vulnerability reporting](https://github.com/appstrate/appstrate/security/advisories/new) or email `security@appstrate.dev`. See [SECURITY.md](https://github.com/appstrate/appstrate/blob/main/SECURITY.md).
- **Setup help or a general question**: Discord.
- **A change to the AFPS format**: open an issue on the [AFPS spec repository](https://github.com/appstrate/afps-spec/issues). The spec is governed separately from the runtime.
- **Anything else**: `hello@appstrate.dev`.

## Contributing

Bug fixes, documentation, translations, integrations, skills, agents, and features are all welcome. [Contributing](/docs/resources/contributing) covers the workflow and conventions.

## Code of conduct

The project follows the [Contributor Covenant](https://github.com/appstrate/appstrate/blob/main/CODE_OF_CONDUCT.md). Be kind and technical, and assume good faith.
