Whichever category of tool you're evaluating us against, here's the factual matrix. We only list criteria that matter when you ship an agent to a team or embed one inside a product.

Four categories, one page:

- [**Managed runtimes**](#vs-managed-runtimes) : Bedrock AgentCore, Claude Managed Agents, Google Gemini Enterprise Agent Platform, Foundry Agent Service (Microsoft).
- [**Personal agents**](#vs-personal-agents) : OpenClaw, Hermes, NanoBot, ZeroClaw, NemoClaw.
- [**Coding agents**](#vs-coding-agents) : Cursor, Claude Code, Antigravity, Windsurf.
- [**Workflow builders**](#vs-workflow-builders) : n8n, Zapier, Make, LangGraph, Dify.

> **AFPS vs Skills.** All five personal agents ship Anthropic's `SKILL.md` convention (or a close variant). AFPS is not a competitor to Skills: it is a **superset** that wraps them in an npm-style package model with `manifest.json`, semantic versioning, declared `dependencies`, and scoped names. A single `SKILL.md` is still a valid AFPS unit. AFPS adds the parts npm added on top of CommonJS: reproducible installs, semver, and integrity checks.

**Pick a personal agent over Appstrate if:** you're the only user, running on your own hardware, and don't need end-user isolation, audit, or a REST API. NemoClaw narrows some gaps for regulated environments, at the cost of GPU infrastructure and alpha-stage stability.

## Architecture notes

Two architectural choices explain most of the differences above.

**Sidecar isolation.** Most platforms run agents in the same process as the server, with credentials in environment variables the LLM can read. Appstrate isolates each run on its own network (a Docker network or a Firecracker microVM) with a sidecar that injects credentials just before outbound requests. The agent only talks to the sidecar over MCP and never sees the secret material. See [Architecture](/docs/resources/architecture).

**Prompt-driven, not graph-driven.** Workflow tools define a step sequence: fetch, filter, send. Appstrate gives a goal: "summarize important emails and notify me on Slack". The agent decides how. More adaptable, simpler to author, less predictable (mitigated with output schemas and retries).
