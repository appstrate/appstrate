## What is the Appstrate API?

A REST API described by [OpenAPI 3.1](https://spec.openapis.org/oas/v3.1.0). Everything the dashboard does is available over HTTP: agents, runs, schedules, webhooks, providers, end-users, organizations, applications, API keys, models, packages, and realtime streams.

## Base URL

A local Appstrate instance serves the API at:

```
http://localhost:3000
```

All endpoints live under `/api/...`. In production, swap the base for your deployed `APP_URL`. There is no URL version prefix: every route is versioned through the `Appstrate-Version` header (see [Authentication](/docs/api/authentication#required-headers)).

## OpenAPI spec

The full OpenAPI 3.1 document is served at:

```
GET /api/openapi.json
```

Swagger UI is available at `/api/docs`.
