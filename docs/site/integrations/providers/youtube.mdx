## Overview

YouTube is Google's video platform. The integration lets agents read channel and video data, and upload videos when the matching scopes are granted.

Integration: `@appstrate/youtube` (version 1.0.5), reached through the `api_call` tool. For how this works, see [How integrations work](/docs/integrations/how-integrations-work).

## Authentication

| Property            | Value                                              |
| ------------------- | -------------------------------------------------- |
| Type                | `oauth2`                                           |
| Credential sent as  | `Authorization: Bearer <credential>`               |
| Default scopes      | `https://www.googleapis.com/auth/youtube.readonly` |
| Token endpoint auth | `client_secret_post`                               |

### Scopes

The scopes below are the catalogue the integration declares. An agent gets the default scopes plus any it lists under `scopes` in its `integrations_configuration`.

| Scope                                                                 | Description                                      | Default |
| --------------------------------------------------------------------- | ------------------------------------------------ | ------- |
| `https://www.googleapis.com/auth/youtube.readonly`                    | Read-only access (videos, channels, playlists)   | yes     |
| `https://www.googleapis.com/auth/youtube`                             | Full access (manage account)                     |         |
| `https://www.googleapis.com/auth/youtube.upload`                      | Upload videos                                    |         |
| `https://www.googleapis.com/auth/youtube.force-ssl`                   | Manage videos, comments, captions (SSL required) |         |
| `https://www.googleapis.com/auth/youtubepartner`                      | YouTube Partner (content & rights management)    |         |
| `https://www.googleapis.com/auth/youtube.channel-memberships.creator` | Read channel memberships                         |         |

## Authorized URIs

The sidecar sends the credential only to URLs that match one of these patterns:

- `https://www.googleapis.com/youtube/**`
- `https://youtube.googleapis.com/**`
- `https://www.googleapis.com/upload/youtube/**`

## Connect YouTube

An administrator registers an OAuth client once, then members connect their own accounts.

<Steps>
<Step>

Create or select a Google Cloud project ([open](https://console.cloud.google.com/projectcreate)).

</Step>
<Step>

Enable the API you need in that project.

</Step>
<Step>

Configure the OAuth consent screen ([open](https://console.cloud.google.com/auth/overview)).

</Step>
<Step>

Create an OAuth client ID of type "Web application" and register the Appstrate redirect URI ([open](https://console.cloud.google.com/apis/credentials)).

</Step>
<Step>

Register the redirect URI in the OAuth client's authorized redirect URIs: it is `APP_URL` followed by `/api/integrations/callback`, also shown in the integration's setup panel.

</Step>
<Step>

In Appstrate, open the integration and register the OAuth client (client ID and client secret). See [How integrations work](/docs/integrations/how-integrations-work#setting-up-an-integration).

</Step>
</Steps>

## Use it in an agent

```json
{
  "dependencies": {
    "integrations": { "@appstrate/youtube": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/youtube": {
      "tools": ["api_call"]
    }
  }
}
```

Example prompt:

```
List the ten latest videos of my channel with their view counts and write a weekly performance note.
```
