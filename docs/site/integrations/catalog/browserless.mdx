## Overview

`@appstrate/browserless` is a remote MCP integration backed by Browserless's MCP server. It gives an agent headless browsers: scrape a page as markdown, HTML, links, a screenshot or a PDF, crawl or map a site, search the web, fetch a page in its native format, run a Lighthouse audit or Puppeteer code.

The server URL is a connection variable, so the same integration serves Browserless Cloud and your own instance. On Cloud it also exposes account usage, sessions, logs and a live viewer link, and its calls consume Browserless units. A self-hosted open-source Browserless runs only Puppeteer code and the built-in browsing recipes.

Three tools are hidden from agents and cannot be selected: `browserless_agent`, `browserless_link_checkout` and `browserless_link_connect`.

## Connect Browserless Cloud

Activate the integration, then open it and fill in the hosted connect form. Keep the prefilled URL `https://mcp.browserless.io` and paste the API token of your Browserless account ([https://browserless.io/account](https://browserless.io/account)).

## Connect your own instance

<Steps>
<Step>

Run the `@browserless.io/mcp` server with `TRANSPORT=httpStream` and point it at your Browserless instance with `BROWSERLESS_API_URL`. It is not part of Appstrate.

</Step>
<Step>

In the connect form, enter the address of that MCP server without the trailing `/mcp`, and the `TOKEN` of your Browserless instance as the API token.

</Step>
<Step>

If the address is private or plain `http`, an operator must list its host in `EGRESS_ALLOW_INTERNAL_HOSTS`, or the connection is refused. See [Environment Variables](/self-hosting/environment-variables).

</Step>
</Steps>

The URL is not a secret: it is stored in plaintext, shown on the connection and changed only by reconnecting. The token is delivered to the server as a bearer token.

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/browserless": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/browserless": {
      "tools": ["browserless_smartscraper", "browserless_search"]
    }
  }
}
```

Example prompt:

```
Search the web for the three most recent announcements from our main
competitor, scrape each page as markdown and summarise them.
```
