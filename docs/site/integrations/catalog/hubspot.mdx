## Overview

HubSpot is a CRM and marketing platform. The integration lets agents read and write contacts, companies and deals through the HubSpot API.

Integration: `@appstrate/hubspot`, reached through the `api_call` tool. For how this works, see [How integrations work](/integrations/how-integrations-work).

## Connect HubSpot

An administrator registers an OAuth client once, then members connect their own accounts.

<Steps>
<Step>

Create a public app from a HubSpot developer account ([open](https://app.hubspot.com/developer)).

</Step>
<Step>

Register the redirect URI as the app's redirect URL: it is `APP_URL` followed by `/api/integrations/callback`, also shown in the integration's setup panel.

</Step>
<Step>

In Appstrate, open the integration and register the OAuth client (client ID and client secret). See [How integrations work](/integrations/how-integrations-work#setting-up-an-integration).

</Step>
</Steps>

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/hubspot": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/hubspot": {
      "tools": ["api_call"],
      "scopes": ["crm.objects.deals.read"]
    }
  }
}
```

`api_call` has no per-tool scopes, so scopes beyond the defaults are listed explicitly (here `crm.objects.deals.read`).

Example prompt:

```
Every morning, list the deals that moved to a new stage yesterday and send the owner a one-line recap.
```
