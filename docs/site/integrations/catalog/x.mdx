## Overview

X is a social network. The integration uses the X API v2 with OAuth 2.0 and PKCE, and requests `offline.access` by default so tokens can refresh.

Integration: `@appstrate/x`, reached through the `api_call` tool. For how this works, see [How integrations work](/integrations/how-integrations-work).

## Connect X (Twitter)

An administrator registers an OAuth client once, then members connect their own accounts.

<Steps>
<Step>

Create a project and an app in the X developer portal, then enable OAuth 2.0 ([open](https://developer.x.com/en/portal/dashboard)).

</Step>
<Step>

Register the redirect URI as the app's callback URI: it is `APP_URL` followed by `/api/integrations/callback`, also shown in the integration's setup panel.

</Step>
<Step>

In Appstrate, open the integration and register the OAuth client (client ID and client secret). See [How integrations work](/integrations/how-integrations-work#setting-up-an-integration).

</Step>
</Steps>

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/x": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/x": {
      "tools": ["api_call"],
      "scopes": ["tweet.write"]
    }
  }
}
```

`api_call` has no per-tool scopes, so scopes beyond the defaults are listed explicitly (here `tweet.write`).

Example prompt:

```
Summarize the replies to my last three posts and draft an answer to each one for my review.
```
