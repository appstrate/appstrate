## Overview

LinkedIn is a professional network. The integration lets agents read the connected member's profile and, with the matching scopes, post on their behalf or work with organization pages and ads.

Integration: `@appstrate/linkedin` (version 1.0.5), reached through the `api_call` tool. For how this works, see [How integrations work](/integrations/how-integrations-work).

## Authentication

| Property            | Value                                |
| ------------------- | ------------------------------------ |
| Type                | `oauth2`                             |
| Credential sent as  | `Authorization: Bearer <credential>` |
| Default scopes      | `openid`, `profile`, `email`         |
| Token endpoint auth | `client_secret_post`                 |
| PKCE                | `S256`                               |

### Scopes

The scopes below are the catalogue the integration declares. An agent gets the default scopes plus any it lists under `scopes` in its `integrations_configuration`.

| Scope                   | Description                             | Default |
| ----------------------- | --------------------------------------- | ------- |
| `openid`                | OpenID Connect (required)               | yes     |
| `profile`               | Read name & profile picture             | yes     |
| `email`                 | Read email address                      | yes     |
| `w_member_social`       | Post on behalf of member                |         |
| `r_organization_social` | Read organization posts                 |         |
| `w_organization_social` | Post on behalf of organization          |         |
| `rw_organization_admin` | Manage organization pages               |         |
| `r_ads`                 | Read ads data                           |         |
| `r_ads_reporting`       | Read ads reporting                      |         |
| `rw_ads`                | Manage ad campaigns                     |         |
| `r_basicprofile`        | Read full profile (headline, positions) |         |
| `r_liteprofile`         | Read basic profile (name, photo)        |         |

## Authorized URIs

The sidecar sends the credential only to URLs that match one of these patterns:

- `https://api.linkedin.com/**`

## Connect LinkedIn

An administrator registers an OAuth client once, then members connect their own accounts.

<Steps>
<Step>

Create an app in the LinkedIn developer portal and request the "Sign In with LinkedIn using OpenID Connect" product ([open](https://www.linkedin.com/developers/apps)).

</Step>
<Step>

Register the redirect URI in the app's authorized redirect URLs: it is `APP_URL` followed by `/api/integrations/callback`, also shown in the integration's setup panel.

</Step>
<Step>

In Appstrate, open the integration and register the OAuth client (client ID and client secret). See [How integrations work](/integrations/how-integrations-work#setting-up-an-integration).

</Step>
</Steps>

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/linkedin": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/linkedin": {
      "tools": ["api_call"],
      "scopes": ["w_member_social"]
    }
  }
}
```

`api_call` has no per-tool scopes, so scopes beyond the defaults are listed explicitly (here `w_member_social`).

Example prompt:

```
Draft a post from this week's release notes and publish it to my profile after I approve it.
```
