## Overview

Stripe is a payment processing platform. The integration lets agents call the Stripe API with a key you provide.

Integration: `@appstrate/stripe` (version 1.0.3), reached through the `api_call` tool. For how this works, see [How integrations work](/docs/integrations/how-integrations-work).

## Authentication

| Property           | Value                                |
| ------------------ | ------------------------------------ |
| Type               | `api_key`                            |
| Credential sent as | `Authorization: Bearer <credential>` |

## Authorized URIs

The sidecar sends the credential only to URLs that match one of these patterns:

- `https://api.stripe.com/**`

## Connect Stripe

Create a Stripe API key in the Stripe dashboard (a secret key starts with `sk_`; a restricted key limits what agents can do) and paste it into the hosted connect form. Prefer a restricted key with only the permissions the agent needs.

## Use it in an agent

```json
{
  "dependencies": {
    "integrations": { "@appstrate/stripe": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/stripe": {
      "tools": ["api_call"]
    }
  }
}
```

Example prompt:

```
Every Monday, list last week's failed payments with the customer email and the failure reason.
```
