## Overview

`@appstrate/playwright-mcp` is a remote MCP integration for Microsoft's Playwright MCP server, which you run yourself. Each run gets a fresh browser context, driven step by step through accessibility snapshots: navigate, click, type, fill forms, select options, hover, drag, handle dialogs, manage tabs, wait, read console and network traffic, evaluate JavaScript and take screenshots. Started with `--caps vision`, the server adds coordinate mouse tools. Started with `--cdp-endpoint`, it drives an existing Chromium instead.

Three tools are hidden from agents and cannot be selected: `browser_run_code_unsafe` (arbitrary code in the server process) and `browser_file_upload` and `browser_drop` (the two that read files from the server's disk).

## What to deploy

Playwright MCP has no authentication of its own, and the browser reaches whatever its container reaches. The manifest asks for the following.

- **The image** `mcr.microsoft.com/playwright/mcp`, started with `--isolated`. It is required even with `--cdp-endpoint`: without it every run shares one profile, so cookies and sessions leak from one user to the next.
- **`--allowed-hosts`** listing the exact `Host` header the server receives, port included. Behind a reverse proxy, that is the one the proxy forwards.
- **A reverse proxy** that checks the access token. Expose the server only behind it.
- **A restricted network.** Put the browser on a network with limited egress, for example with `--proxy-server` pointing to an egress proxy, and never next to internal services.

## Connect

<Steps>
<Step>

Activate the integration, open it and fill in the connect form: the server address without `/mcp`, and the access token.

</Step>
<Step>

Configure your reverse proxy to expect that token in an `Authorization: Bearer` header. The form requires the token, but only your proxy checks it.

</Step>
<Step>

For a private address or a plain `http` URL, an operator must list the host in `EGRESS_ALLOW_INTERNAL_HOSTS`, or Appstrate refuses it. See [Environment Variables](/self-hosting/environment-variables).

</Step>
</Steps>

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/playwright-mcp": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/playwright-mcp": {
      "tools": ["browser_navigate", "browser_snapshot", "browser_click", "browser_type"]
    }
  }
}
```

Example prompt:

```
Open our staging site, sign in with the test account from the input, and
report whether the checkout page loads.
```
