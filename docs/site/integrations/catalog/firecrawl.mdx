## Overview

Firecrawl is a web scraping and crawling service. The integration lets agents extract content from web pages with a key you provide.

Integration: `@appstrate/firecrawl` (version 1.0.3), reached through the `api_call` tool. For how this works, see [How integrations work](/integrations/how-integrations-work).

## Authentication

| Property           | Value                                |
| ------------------ | ------------------------------------ |
| Type               | `api_key`                            |
| Credential sent as | `Authorization: Bearer <credential>` |

## Authorized URIs

The sidecar sends the credential only to URLs that match one of these patterns:

- `https://api.firecrawl.dev/**`

## Connect Firecrawl

Create an API key in your Firecrawl account (keys start with `fc-`) and paste it into the hosted connect form.

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/firecrawl": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/firecrawl": {
      "tools": ["api_call"]
    }
  }
}
```

Example prompt:

```
Every week, crawl the blog of each competitor in the "Monitoring" sheet, extract the new articles and write a comparative summary.
```
