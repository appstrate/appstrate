## Overview

ClickUp is a project management platform. Appstrate ships two ClickUp integrations, as separate packages.

| Integration                              | Source     | How the agent reaches ClickUp                                                                   |
| ---------------------------------------- | ---------- | ----------------------------------------------------------------------------------------------- |
| `@appstrate/clickup` (version 1.0.5)     | `api_call` | Calls the ClickUp REST API (v2) directly. Needs an OAuth client registered by an administrator. |
| `@appstrate/clickup-mcp` (version 1.2.3) | Remote MCP | Uses ClickUp's hosted MCP server. The OAuth client is registered automatically at connect time. |

## ClickUp (API): `@appstrate/clickup`

| Property            | Value                                |
| ------------------- | ------------------------------------ |
| Type                | `oauth2`                             |
| Credential sent as  | `Authorization: Bearer <credential>` |
| Token endpoint auth | `client_secret_post`                 |

ClickUp does not use OAuth scopes: the token carries the permissions of the member who authorizes. Authorized URI: `https://api.clickup.com/**`.

## ClickUp (MCP): `@appstrate/clickup-mcp`

| Property            | Value                                |
| ------------------- | ------------------------------------ |
| Type                | `oauth2`                             |
| Credential sent as  | `Authorization: Bearer <credential>` |
| Default scopes      | `read`, `write`                      |
| Token endpoint auth | `none`                               |

The platform discovers ClickUp's authorization server and registers a public client on first connect, so an administrator has nothing to configure. The `read` and `write` scopes are requested by default, and ClickUp's own workspace role is the only access control behind them. Authorized URI: `https://mcp.clickup.com/**`.

The integration declares 61 tools (tasks, lists, folders, comments, documents, time tracking, chat and more). `clickup_execute_operator` and `clickup_get_operators` are hidden from agents, because they run whatever operators ClickUp enables server-side, which a per-tool selection cannot bound. ClickUp applies its own rate limits to the MCP server.

## Connect ClickUp

For the MCP integration, activate it and members click Connect. For the API integration:

<Steps>
<Step>

Create an OAuth app under Settings, Apps ([open](https://app.clickup.com/settings/team/apps)).

</Step>
<Step>

Register the redirect URL `APP_URL` followed by `/api/integrations/callback`, as shown in the integration's setup panel.

</Step>
<Step>

In Appstrate, open the integration and register the OAuth client (client ID and client secret). See [How integrations work](/docs/integrations/how-integrations-work#setting-up-an-integration).

</Step>
</Steps>

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/clickup-mcp": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/clickup-mcp": {
      "tools": ["clickup_filter_tasks", "clickup_get_task", "clickup_create_task"]
    }
  }
}
```

Example prompt:

```
Every evening, list the tasks assigned to me that are overdue, and create a
follow-up task for each one in the "Triage" list.
```
