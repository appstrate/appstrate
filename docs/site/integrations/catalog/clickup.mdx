## Overview

ClickUp is a project management platform. Appstrate ships two ClickUp integrations, as separate packages.

| Integration              | Source     | How the agent reaches ClickUp                                                                   |
| ------------------------ | ---------- | ----------------------------------------------------------------------------------------------- |
| `@appstrate/clickup`     | `api_call` | Calls the ClickUp REST API (v2) directly. Needs an OAuth client registered by an administrator. |
| `@appstrate/clickup-mcp` | Remote MCP | Uses ClickUp's hosted MCP server. The OAuth client is registered automatically at connect time. |

The token carries the permissions of the member who authorizes: ClickUp's own workspace role is the only access control behind it. In the MCP integration, `clickup_execute_operator` and `clickup_get_operators` are hidden from agents, because they run whatever operators ClickUp enables server-side, which a per-tool selection cannot bound. ClickUp applies its own rate limits to the MCP server.

## Connect ClickUp

For the MCP integration, activate it and members click Connect. For the API integration:

<Steps>
<Step>

Create an OAuth app under Settings, Apps ([open](https://app.clickup.com/settings/team/apps)).

</Step>
<Step>

Register the redirect URL `APP_URL` followed by `/api/integrations/callback`, as shown in the integration's setup panel.

</Step>
<Step>

In Appstrate, open the integration and register the OAuth client (client ID and client secret). See [How integrations work](/integrations/how-integrations-work#setting-up-an-integration).

</Step>
</Steps>

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/clickup-mcp": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/clickup-mcp": {
      "tools": ["clickup_filter_tasks", "clickup_get_task", "clickup_create_task"]
    }
  }
}
```

Example prompt:

```
Every evening, list the tasks assigned to me that are overdue, and create a
follow-up task for each one in the "Triage" list.
```
