## Overview

Pinterest is a visual discovery platform. The integration lets agents read account data and, with the matching scopes, manage boards and pins.

Integration: `@appstrate/pinterest` (version 1.0.5), reached through the `api_call` tool. For how this works, see [How integrations work](/docs/integrations/how-integrations-work).

## Authentication

| Property            | Value                                |
| ------------------- | ------------------------------------ |
| Type                | `oauth2`                             |
| Credential sent as  | `Authorization: Bearer <credential>` |
| Default scopes      | `user_accounts:read`                 |
| Token endpoint auth | `client_secret_basic`                |

### Scopes

The scopes below are the catalogue the integration declares. An agent gets the default scopes plus any it lists under `scopes` in its `integrations_configuration`.

| Scope                | Description             | Default |
| -------------------- | ----------------------- | ------- |
| `boards:read`        | Read boards             |         |
| `boards:write`       | Create & edit boards    |         |
| `pins:read`          | Read pins               |         |
| `pins:write`         | Create & edit pins      |         |
| `user_accounts:read` | Read user profile       | yes     |
| `ads:read`           | Read ads data           |         |
| `ads:write`          | Manage ads campaigns    |         |
| `catalogs:read`      | Read product catalogs   |         |
| `catalogs:write`     | Manage product catalogs |         |

## Authorized URIs

The sidecar sends the credential only to URLs that match one of these patterns:

- `https://api.pinterest.com/**`

## Connect Pinterest

An administrator registers an OAuth client once, then members connect their own accounts.

<Steps>
<Step>

Create an app in the Pinterest developer portal ([open](https://developers.pinterest.com/apps/)).

</Step>
<Step>

Register the redirect URI in the app's redirect URIs: it is `APP_URL` followed by `/api/integrations/callback`, also shown in the integration's setup panel.

</Step>
<Step>

In Appstrate, open the integration and register the OAuth client (client ID and client secret). See [How integrations work](/docs/integrations/how-integrations-work#setting-up-an-integration).

</Step>
</Steps>

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/pinterest": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/pinterest": {
      "tools": ["api_call"],
      "scopes": ["boards:write", "pins:write"]
    }
  }
}
```

`api_call` has no per-tool scopes, so scopes beyond the defaults are listed explicitly (here `boards:write`, `pins:write`).

Example prompt:

```
Create a board named "Spring collection" and add the ten pins from the attached list.
```
