## Overview

Brevo is an email marketing and CRM platform. The integration lets agents call the Brevo API v3 with a key you provide.

Integration: `@appstrate/brevo` (version 1.0.2), reached through the `api_call` tool. For how this works, see [How integrations work](/integrations/how-integrations-work).

## Authentication

| Property           | Value                   |
| ------------------ | ----------------------- |
| Type               | `api_key`               |
| Credential sent as | `api-key: <credential>` |

## Authorized URIs

The sidecar sends the credential only to URLs that match one of these patterns:

- `https://api.brevo.com/**`

## Connect Brevo

Create an API v3 key in your Brevo account and paste it into the hosted connect form. Brevo expects the key in an `api-key` header, which the integration sets for you.

## Use it in an agent

Excerpt of the agent manifest:

```json
{
  "dependencies": {
    "integrations": { "@appstrate/brevo": "^1.0.0" }
  },
  "integrations_configuration": {
    "@appstrate/brevo": {
      "tools": ["api_call"]
    }
  }
}
```

Example prompt:

```
Add the contacts from the attached sheet to the "Newsletter" list, skipping the ones already subscribed.
```
